# Roadmap

Ideas, roughly in order. Open an issue before starting on one.

1. Start at login: launchd and systemd examples.
2. A self-check that warns on the page when Teams' page changed and a selector
   no longer matches.
3. Find chats beyond those in Teams' sidebar (through the chat service API).
4. Channel posts, not only chats.
5. Other chat platforms behind the same MCP tools.
6. A package on PyPI.
